# 共享转写词库

这两份 UTF-8 词表按用户授权同步到仓库，便于在不同电脑间继续使用。每行一个词，`#` 开头的说明不参与导入。

| 文件 | 词条数 | 使用方式 |
|---|---:|---|
| [uiux-terms.txt](uiux-terms.txt) | 511 | 通用 UI/UX 和游戏交互术语；软件内置默认词表 |
| [燕云十六声-合并去重.txt](燕云十六声-合并去重.txt) | 1112 | 可选游戏词库；在燕云录制预设中手动选择 |

截至 2026-10-08，两份词表合并去重为 1621 条，未超过当前转写接口的 2000 条上限。已包含本机场次整理时核对并追加的游戏与 UX 术语。

在另一台电脑拉取仓库后，可将这两份 TXT 复制到安装目录的 `vocabularies`，再在预设的「录制与转写 → 语言与词库」中重新选择并保存。预设保存的是独立词条快照，仅替换磁盘文件不会自动刷新旧预设。已有预设也可通过记录器支持的词库刷新接口更新，见 [词库接口说明](../docs/vocabulary-agent.md)。

UI/UX 词表为项目原创汇总，沿用 MIT 许可证。燕云词表由文件头列出的三份搜狗细胞词库合并去重，再追加场次中核对的词条；保留原始来源说明，不将第三方词库内容重新声明为项目原创或 MIT 授权内容。

软件打包仍只默认收录 UI/UX 词表；燕云词表作为仓库中的可选文件提供。私人词库维护记录、补词备份、预设、密钥、逐字稿和录像不随这两份词表同步。
