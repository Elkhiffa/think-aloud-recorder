# 改版决定（2026-10-19）

本文件记录 2026-10-19 与用户逐项确认的改版决定，是本轮前端改版的依据。改版在分支 `feat/frontend-redesign` 上进行；性能修复另开任务，不在本轮。

## 产品骨架

- 主窗口是纯录音机。它常年开在副屏的小窗里，按 720 宽设计，更宽时只加留白。
- 场次库和洞察合并成“资料台”大窗口，用标题栏页签切换“场次 / 洞察”。资料台全局只开一个，跟随主窗口的当前项目。
- 三个窗口（主窗口、资料台、回看）都去掉系统标题栏，改用自绘标题栏。标题栏只当窗口外框用：左侧放小标，中间是可拖动的空白，右侧是三个窗口按钮，不放页签和功能。自绘标题栏要补齐：拖动、双击最大化、拖到屏幕边缘贴边、四边四角改大小、窗口阴影。Windows 11 鼠标停在最大化按钮上弹出的分屏布局，这一项不提供。

## 主窗口

- **页面标题**：页面的第一个区块就是标题。当前游戏名用大字，其他游戏跟在旁边用小字，点一下就切换；放不下时收进“更多”。不区分主游戏和竞品。
- **空闲时**，只显示这几样：
  - 录制键；
  - 上一场：标题、日期和时长、问题数、一句原话；
  - “全部场次 →”和“洞察 →”两行。

  录制方案不露出，项目名不重复出现。
- **异常时**：隐藏所有就绪小圆点，出问题的那一项改成醒目提示，写清原因，并附“去设置”或“重新检查”。
- **录制中**：整页只剩计时、麦克风音量、键鼠和手柄记录状态（含游戏是否在前台）、结束按钮。
- **刚结束**：上一场的位置依次显示保存中、转写中、待整理、已整理 N 个问题。
  - 待整理时附“复制整理指令”：把场次路径和整理提示复制到剪贴板，内容跟随单场整理的交接文档。工具不内置 agent，也不上传任何东西。
  - 失败时，也在这个位置醒目地显示。
- **原话的挑选规则**：优先“阻碍 > 操作成本 > 困惑 > 负面”，只取置信度高的，长度 8–24 字，不以语气词开头，原样引用，不做任何改写。
- **新项目还没有场次时**：正文写“还没有记录。点开始录制，边玩边说出你此刻的想法。”；“全部场次”和“洞察”两行先不显示。

## 资料台

- 标题栏左侧是项目名，接着是“场次 / 洞察”两个页签，右侧是窗口按钮。
- **场次视图**：
  - 左边是按月分组的列表，月份标题吸顶。每行有页边日期、标题（未命名的显示“未命名”加前两个活动标题）、时长、状态、问题数和一条细色条。
  - 右边是选中这一场的详情：按类型分组的原话、活动、问题分布，以及全部操作——回看、整理或重试、复制整理指令、重命名、导出、资料文件夹、原始录像、恢复云端任务。
  - 列表顶部用标签多选筛选：状态（全部 / 待整理 / 已整理 / 失败）和问题类型。排序可选时间或问题数。文字搜索收成一个图标。
- **洞察视图**：保持现有结构，只换视觉。
- **互相跳转**：
  - 场次详情里列出“这一场的证据挂在哪几个洞察下”，点击后切到洞察视图，只看这一场的证据；
  - 洞察里证据卡上的场次名可以点，点击后切到场次视图并选中那一场。

## 设置

- 在主窗口里以覆盖层打开，是一页表单，底部固定“保存 / 取消”。齿轮打开时，默认停在“游戏设置”。
- **游戏设置**（每个游戏各一份）：
  - 显示名称（改名不移动文件夹）；
  - 游戏窗口；
  - 游戏专有词库；
  - 保存位置（只读，可以打开文件夹）。
- **通用设置**：
  - 麦克风；
  - 录制范围、画面质量；
  - 是否记录键鼠与手柄；
  - 转写方式、密钥、转写语言；
  - UI/UX 通用词库；
  - 深浅色；
  - 资料总库位置；
  - 记录方法说明；
  - 版本与更新渠道。
- **向导**只在第一次使用和新建项目时出现。新建项目分三步：
  1. 游戏名、游戏窗口；
  2. 麦克风与转写，第一次使用时才有这一步；
  3. 保存位置，默认是“总库\游戏名”，可以另选。

  “记录方法”说明只在第一次使用时出现。
- 现有设置规则全部保留，包括：
  - 预设保存成功后才保存密钥；
  - 词库并发检查；
  - 资料库复用确认；
  - 部分失败按编辑重试；
  - 录制中锁定设置；
  - 重新连接录制引擎的入口。

## 视觉

- **方向**：田野笔记。红色页边线、页边日期数字、原话引文、目录导引线。录制键是红色胶囊，也是全页唯一的实心色块。
- **字体**：宋体（思源宋体）只用于大标题、日期数字和原话。没有思源宋体的系统退回黑体粗体，不退回系统宋体。其余文字一律用等线或微软雅黑；数字用 Georgia；时间码用 Consolas。
- **尺度**：
  - 间距只用 4 / 8 / 12 / 16 / 24 / 32 / 48；
  - 圆角统一为 4px：按钮、输入框、标签、提示块、录制键一律相同；只有小于 12px 的状态点不受限制；
  - 字号只用六档：12 / 14 / 16 / 20 / 28 / 48。
- **问题类型配色**：困惑是赭黄，阻碍是朱红，操作成本是靛蓝，负面是紫，其余类型都是浅灰。三个窗口统一使用这一套；颜色只用在“问题”上。
- **深浅色**：默认跟随系统，在设置里修改，三个窗口同步。
- **动效**：只在空闲切到录制中、录制中切到保存、异常提示出现这三处使用。系统开启“减少动画”时全部关闭。

## 数据与迁移

- **项目**：一款游戏就是一个项目，各自一个资料库文件夹。软件里不登记主游戏和竞品的关系：如果只是预研某个品类，可能根本没有主游戏。
- **资料总库**：下面按游戏分文件夹。现有资料库根目录的内容搬进 `燕云十六声\`，只有 `.obsidian`（Obsidian 对整个库的配置）、`分析`、`.experience` 三样留在总库根目录（2026-10-20 用户确认）。跨游戏分析放在总库根目录的 `跨游戏分析\` 下。这一轮只建好约定，不做界面。
- **搬迁方式**：由用户在没人使用资料库时亲手运行脚本：
  1. 先预览要做什么；
  2. 在同一磁盘内移动，硬链接不受影响；
  3. 搬完自动核对：45 场都在、对应 0 失效、报告引用 0 未解析；
  4. 同步改写安装版配置里的路径，改之前先备份。

  搬迁放在开发版验证过新结构之后进行，搬之前通知内容分析会话和 Codex 暂停。
- **不改名的东西**：项目改名不移动文件夹；场次文件夹名不改，新场次也沿用现在的命名规则。
- **新项目位置**：默认放在总库下，也可以另选位置；各窗口一律按项目记下的路径查找。
- **现有预设的迁移**：
  - 通用设置取自当前正在用的预设；
  - 每个资料库对应一个游戏，它的游戏窗口和游戏词库取自对应的预设；
  - 同一资料库下有多套预设时，以当前那套为准，其余的备份；
  - 原配置先备份到 `state/`。

## 记进 roadmap

- 用语音做标记：整理时从逐字稿识别“这里记一下”这类说法，录制中不用多按任何东西。
- 支持更多转写 API 渠道。
- 跨游戏分析的界面，按 `跨游戏分析\` 下的路径呈现。

## 第二轮追问的修订（2026-10-19）

- 去掉“第 N 场”：用户在两台机器上交替录制，本地无法知道下一场的编号。
- 不再区分主游戏和竞品，页签只是不同的游戏。
- 日期挂在场次标题的左侧，两者之间不加分隔线。
- 页边线和窄栏是否保留、选哪个视觉方向，由新一轮主界面探索决定，样稿见 `work/redesign/explore/`。

## 第三轮：视觉定稿（2026-10-19）

视觉稿见 `work/redesign/b/`。

**方向**：选定 B（笔记 · 窄栏）。

**主窗口的构成**：
- 左侧 56px 窄栏，右边缘是一条红色页边线。窄栏顶部放 28px 的标记，左下角只放“记录方法”和“设置”两个图标。
- 窗口顶部就是页面标题：当前游戏名用 48 宋体，其他游戏用 20 宋体，后面跟一个“＋”图标。页签顺序固定，不因切换而重排。
- 放不下时，当前游戏名保持完整，其他游戏从后往前收进“更多”，仍放不下时“＋”也收进去（显示为“＋ 新游戏”）；只有当前游戏名单独都放不下时才截断。
- 内容只有一条左边缘，用两条分割线切成三段：
  - 第一段：录制键加“已就绪”；
  - 第二段：“上一场”标题和上一场的内容，下面是“全部场次 ······ N 场 →”。两者是同级标题，表示上一场是全部场次中的一场；
  - 第三段：“洞察 ······ N 个 →”，下面写最新报告的日期。
- 日期挂在场次标题左侧，两者之间没有分隔线。

**异常时**：提示块放在灰掉的录制键右侧，与它并排；第一段的高度不变，上一场的原话暂时收起。提示块与录制键同高（56px），不滚动：只显示第一条原因、最多两行；有多条原因或一条写不下时，旁边出现“全部 N 项 / 查看全文”，点开列出全部原因（2026-10-20 用户确认：报错信息不应该滚动）。

**录制中**：
- 第一段：计时和结束按钮；
- 第二段：收音与操作；
- 第三段：一句提示语。

页签只保留当前游戏，并注明录制中不能切换。

**窗口尺寸**：初始尺寸改为 720×600，与最小尺寸相同。原来的初始尺寸是 920×1040。

**设置**：
- 设置是软件层级的入口，因为它在窄栏里，和具体游戏隔开。
- 一级页签是“游戏 | 通用”。“游戏”下面的二级页签是各个游戏，加一个“＋ 新游戏”。打开设置时，默认停在当前游戏。
- 版本与更新整体收进“通用”。软件启动时检查一次版本（只读取 GitHub 上的版本信息）；有新版本时，在齿轮、“通用”页签和“版本与更新”这一行上都挂红点。
- 没有修改时，底栏只显示“关闭”；有未保存的修改时，显示提示文字和“取消 / 保存”。

**新建游戏**：分两步，“游戏与窗口”和“保存位置”。麦克风和转写只在首次使用时进入向导。

**设备选择的归属**：录制范围和显示器属于通用设置，所有游戏共用；游戏页只有游戏窗口，录制整个显示器时改为一行说明。设备读取结果和“刷新设备”放在设置页顶部，游戏页和通用页（向导的“设备与转写”）都能看到。首次设置的“设备与转写”一步同时显示通用词库，内置的 UI/UX 词库在这里，不算某个游戏的词库。

**资料台**：
- 标题是游戏名（28 宋体），后面是同级的“场次 / 洞察”两个页签。
- 窄栏只放标记。
