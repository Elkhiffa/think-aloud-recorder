此为上一轮历史记录。用户反馈实际默认窗口仍过小，后续策略已改为
[按可用窗口适配](review-viewport-validation.md)，下述固定初始目标不再生效。

超宽视频的初始尺寸现在同时按 900 CSS px 最小宽度、540 CSS px
最小高度以及视频可见画面的原始比例计算。理想宽度为
`max(900, 540 × 宽高比)`；可用窗口空间和右栏的最低可读宽度仍是硬约束。
空间不足时画面等比缩小，不拉伸或额外裁切。录制时已验证的去黑边范围
仍按其可见比例计算，用户可以切回原画面。

未手动调整分隔线时，放大窗口会重新满足这一目标，避免初次在较小窗口
打开后永久停留在较矮的视频尺寸。手动拖动或用键盘调整后继续尊重用户
选择的左栏宽度；双击分隔线或按 Enter 恢复自动尺寸。

本轮布局继续沿用现有纸色、深灰正文和陶红交互点缀，字体及对齐保持不变。
