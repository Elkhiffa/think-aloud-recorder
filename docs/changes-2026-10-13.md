# Think Aloud 0.8.0

从单场回看扩展到跨场次分析：外部 agent 把每场整理成可追溯的判断实例，在资料库层面归到议题；记录器新增「洞察」窗口，从分析报告一路点到某场某时刻的回看。包含 0.7.8 的预设设备识别修复。

## 洞察窗口

- 主窗口场次列表右上角的「洞察」打开当前资料库的洞察窗口。
- 左栏显示跨场次分析 agent 写进资料库 `洞察/*.md` 的报告；引用缩小显示，点击后右栏定位到对应证据。工具不撰写报告，只展示并核对引用。
- 右栏按议题 → 子议题 → 判断实例排列，支持证据与反例分开，带可折叠目录；卡片以“类型 + 活动”为标题，界面路径和归入理由弱化。
- 点卡片上的时间段，在新窗口打开该场回看并停在时间段开头；时间段超过 2 分钟时停在说话前 10 秒；不自动播放。
- 「议题确认」页签：边看证据边确认、改标题、并入其他议题或驳回 agent 提出的候选议题。
- 「界面确认」页签：把 agent 提议的界面名收为新界面或并入已有界面；只改界面目录，不改写场次结果。缩略图优先使用 agent 核对过的画面时刻。

## 整理结果与资料库

- 结果格式 v2：判断实例分别记录说出口的时间和所指时刻，可标“指向本场之前”和对照时刻，可引用操作记录；新增“负面评价”类型；界面可标为提议的新界面并记录跳转路线。
- 资料库级议题表支持一级子议题；“议题 → 实例”对应表区分支持与反例；固定的 `BUG` 议题收集记录者明说的缺陷。
- 界面目录、按别名查询界面、bug 原话扫描、报告引用校验等命令见 [本地接口与约定](agent-integration.md)；单场次整理与跨场次分析的 skill 在 `skills/think-aloud-judgments/`、`skills/think-aloud-insight/`。
- 合并议题时，同场次其余对应随结果摘要一起换绑，不再失效。

## 兼容与限制

- 0.7.x 及更早版本只认旧格式的整理结果：在旧版里打开已有 v2 结果的场次会显示“需重新预处理”。升级到 0.8.0 后正常显示。
- 回看窗口和录制功能不依赖 agent；没有整理结果时照常可用。
- 版本号为 0.8.0，个人配置、密钥、词库、录制资料和资料库内容不属于源码或软件包。
