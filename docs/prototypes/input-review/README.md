# 操作回看交互原型

用于确认呈现和交互，尚未连接生产录制、OBS、输入设备或转写服务。demo.mp4 为 32 秒合成场景，fixture.js 为预制操作和原话示例。

版本说明：后续视觉评审已选用固定方向轨，新增“内容区滚轮调进度、时间刻度区滚轮调缩放”，并移除原话浮层的定位按钮和“已固定”文字。本交互原型尚未同步这三项新约定，下方步骤及验证记录描述的是修改前的原型。最新视觉稿与约定见 ../../design/input-review-v1/README.md。

在浏览器打开 index.html，或从本目录启动本机静态服务查看。原型不要求登录、安装插件或连接外部网络。

建议体验：

1. 初始停在 4.8 秒，查看长按 W 与 A、Q、鼠标左键的真实重叠区间，切换当前按键和设备图。
2. 用底部示例入口跳到 Xbox 和 DualSense，检查同一段视频中的设备切换。
3. 查看切出目标窗口/手柄断开期间的缺口，确认不会误显示为没有操作或持续按住。
4. 播放或暂停时点击“模拟转写完成”：视频位置、播放状态和倍速保持，原话页签解锁，时间轴原话轨加入条目。
5. 在原话条上悬停查看，点击固定文本卡，点击其它位置或 Escape 关闭。卡片定位与原话条固定是两个独立动作。
6. 视频右侧的操作时间轴内部，左起为纵向时间刻度、固定宽度原话轨、紧凑键位区。拖动播放进度，检查键位条和底部当前操作同步；手动滚动时间轴时视频保持不动。
7. 底部“对照方案”切换“紧凑排列”和“固定方向轨”。后者在原话右侧预留方向输入（WASD、左摇杆）、指向输入（鼠标移动、右摇杆）两条区域，其余按键继续紧凑靠左排列。这是待评审候选，尚未替换已确认方案。
8. 用“时间轴缩放 · 细看短按”观察 8.5–9.4 秒的三个 E 短按。条高始终对应实际持续时间，不将临近按键合并。

本轮验证（2026-09-22）：在浏览器实际操作检查了视频与三种底部模式的位置稳定、32 秒媒体解码、时间轴独立滚动、设备热切、暂停/播放/倍速中转写状态更新，以及原话固定/外部点击/Escape 关闭。1280×720、960×720 和浅/深色主题已查看；较窄桌面窗口无页面横向溢出。

独立体验检查通过上述核心流程，另发现键盘焦点滚动导致原话卡片消失；修正后主代理重走“首个 W → Shift+Tab → 屏外原话 3”，已确认全文保持可见、视频时间不变且跟随状态不被误改。未将合成数据检查视为真实键鼠、Xbox 或 DualSense 采集验收。

已确认的正式范围与后续顺序见 ../../input-recording-design-scope.md。此原型的合成演示不能证明手柄兼容、真实采集准确或录制同步精度。
