# 0.7.7 源码与词库同步

本轮将已在本机交付的 0.7.1–0.7.7 改动及截至 2026-10-08 的两份共享词表同步到仓库。源码版本为 `0.7.7`；源码推送与 GitHub Release 附件发布分别进行。

## 主界面与录制反馈

- 主窗口调整为更窄、更高的初始布局，收紧录制预设与场次列表；统一间距和下拉箭头内边距。
- 场次短标题、项目与时间信息、活动详情分层显示；保留手动标题和内容详情。
- 录制时显示时长与麦克风音量条；普通状态不增加说明文字，持续约两分钟无明显声音时提示异常。

## 回看与人工校准

- 播放控制常驻视频画面外，倍速直接展开，双击全屏开关收在设置中。
- 视频下方显示当前或上一句口述，收紧最近操作模块；记录者设置使用较弱的小控件。
- 时间轴增加纵向浏览，改善低倍缩放时的播放线与长按区间可见性。
- 体验事件的时间、标题、描述、问题和备注支持人工编辑，并保留改动供后续预处理读取；备注与证据的展示进一步区分。

## 输入记录与预处理

- 用物理状态核对修复遗漏释放导致的异常长按。
- Windows 输入记录写入遇到短暂文件占用时有限重试；持续失败仍显示采集异常，不推断或补造历史输入。
- 预处理 skill 衔接人工校准，保留以游戏内活动组织事件的原则；改进视觉候选分布及局部取材。
- 词库刷新接口支持预览、应用和回读预设中的词条快照。

## 共享词库

- UI/UX 词表同步为 511 条，比此前仓库增加 67 条。
- 加入可选的燕云十六声词表，共 1112 条，保留搜狗来源与后续补词分组。
- 两份词表合并去重为 1621 条；使用与更新方式见 [共享词库说明](../vocabularies/README.md)。

源码及两份 TXT 可以在另一台电脑继续使用。运行配置、密钥、个人场次、补词备份及维护记录不在本次同步范围中。
