# Think Aloud 0.9.0

三个窗口全部重新设计：主窗口改成 720×520 的录音机，设置改成一页表单，资料台的场次库改成表格加详情。分析改用两份正式 skill：单场整理 `think-aloud-judgments` 和跨场次分析 `think-aloud-insight`。开始和结束录制更快，录像真正开始时会响一声提示音。

## 主窗口

- 左侧是占满全高的录制块，写着游戏名和就绪状态。右侧一栏从上到下是游戏页签、上一场、“全部场次”和“洞察”两张卡；底部是记录方法和设置。
- “上一场”显示日期、名称、四类问题的比例条和计数，以及一句原话。状态依次是已保存、转写中、核对中、待整理。待整理时可以「复制整理指令」，粘贴给 Codex 或 Claude。
- 录制条件不满足时，录制块变灰，右栏顶部只写一条原因；「全部 N 项」列出所有原因。
- 三个窗口都去掉系统标题栏，由页面自己画标题区；拖动、贴边、四边改大小仍交给 Windows。
- 视觉方向是浅暖纸色底，标题用宋体（随包提供 Noto Serif SC Bold），正文用更纱黑体 UI。红色只用于录制和回看播放头。目前只有浅色。

## 设置与首次使用

- 设置改为一页表单：一级页签“游戏 | 通用”，“游戏”下面每个游戏一个二级页签。没有修改时只显示“关闭”，有修改时显示“保存”。
- 设置 → 游戏最下方可以「删除这个游戏」。默认只删除软件里的设置，资料文件夹原样保留；勾选并输入游戏名后，资料文件夹会移到 Windows 回收站。
- 「记录方法」改为左右两栏：左边是怎么说和录完以后怎么整理，右边是四种说法的例子。首次设置的第一步也是这个排版。
- 「记录方法」和首次设置第一步新增「查看 skill 安装方法」，在浏览器打开仓库里的安装说明，不传任何本机信息。

## 资料台

- 场次库是一张按月分组的表格，列有日期、场次、开始、时长、问题数和四类比例、状态。可以搜索，可以按状态和问题类型筛选，可以按时间或问题数排序。
- 选中一场，右边显示详情：回看、复制整理指令、复制资料库路径；打开资料文件夹、重新整理、导出、原始录像和恢复云端任务收在「更多」里。还有四类问题各自的原话、这一场挂在哪些洞察下，以及可以跳到回看的体验事件。
- 场次名可以在详情里原地改名。
- 多选的筛选（问题类型、界面来源）选中后变黑，单选的页签选中后变白，各窗口统一。

## 录制与整理

- 开始录制改为等 OBS 的录制源真正激活再确认；确认后响一声约 0.2 秒的提示音，听到即可切回游戏。提示音会录进回放用的混音轨，不进入纯口述音轨。
- 结束录制的保存轮询更快；开始、结束和就绪检查都记录各阶段耗时。
- 场次列表不再等结果校验完才显示。还在核对的场次显示“核对中”，不会被误报为待整理。

## 分析 skill

- 单场整理 `think-aloud-judgments`：把一场录制整理成可追溯的判断实例。
- 跨场次分析 `think-aloud-insight`：维护议题树；并按用户确认的分析简报，自上而下写洞察报告，定位到游戏属性，按设计规则合并，用三问定严重度，报告校验会核对引用原话。
- 旧的 `think-aloud-preprocess` 由这两份 skill 取代，旧结果继续可读。安装方法见 [Skill 安装与更新](agent-integration.md#skill-安装与更新)。skill 不随软件更新，需要单独安装。

## 修复

- 回看操作时间轴：活动带里的长按标签和长按底色下移了 1 像素，最小缩放时会越出自己的长按，压到下一次按键。已改正。
- 软件内更新和发布检查现在能识别随包的界面字体及其来源记录，不再把它们当作未授权文件拒收。
- 回看「最近操作」选「设备图」时，键盘和手柄图原本只露出最上面一条，要在面板里滚动才看得全。现在这一栏在设备图模式下加高、视频相应缩小约 9%，整张图按面板缩放；设备名并入标题行，只在「自动切换」时显示当前切到的设备。切回「最近按键」或收起后视频恢复原尺寸。
- 旧的 `think-aloud-preprocess` skill 标为已停用，即使被误装，agent 也会先看到“改用 judgments / insight”。
