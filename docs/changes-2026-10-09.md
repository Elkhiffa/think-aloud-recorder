# Think Aloud 0.7.8

打开已保存的录制预设时，自动读取当前游戏窗口、显示器和麦克风。设备身份识别
不再依赖先点击“设置 OBS”，也不会把尚未读取的空列表显示成设备丢失。

- 保留已保存和正在编辑的设备选择；取消编辑、迟到的读取结果或引擎恢复不会
  把游戏窗口改成整个显示器。
- 分别显示正在读取、读取失败、确实缺失、匹配歧义和识别成功；读取期间不重复
  触发刷新，取消和手动编辑仍可使用。
- 设备刷新与录制引擎恢复分开。连接失败、上次录制状态未确认或录制条件检查
  失败时提供对应操作；只有完整检查通过后才允许开始录制。

版本号为 0.7.8，个人配置、密钥、词库和录制资料不属于源码或软件包。
本次不修改 Windows 权限、防火墙规则或自动启动 OBS 的策略。

源码检查和证据边界见
[预设设备识别验证](preset-device-discovery-validation.md)。原生安装、合成录制与
更新保留检查以相应交付记录为准，不能由源码测试结果推定。
