## 限制

原生 Computer Use 的关闭操作先报 `coordinate input geometry is unavailable`，重新激活后通过窗口快捷键正常退出旧记录器并完成更新。安装后的合成回看返回就绪，但桌面控制随后报 `failed to activate captured window`，因此没有宣称完成原生事件页签点击验收。相同生产 HTML/CSS/JS 的交互已在真实 Edge 验证。由本轮启动的两个合成测试进程已清理，正式记录器保持打开。

后续真实使用应先由独立会话预处理一个指定场次，核对引用与事件粒度。当前只提供读取/回写协议和 skill；持续调度属于用户另行授权的外部会话。
