# 2026-09-25 至 09-28 改动汇总

本轮基于 `0.6.0-preview.6`，汇总本地连续迭代后的源码、测试、验证记录和可维护的预处理 skill。源码同步不等于发布新的可下载软件包。

## 录制与操作采集

- Windows 手柄关闭 SDL 的控制器 Raw Input 后端，使用 XInput 路径并保留 DualSense HIDAPI，修复部分录制只有扳机、没有按钮或摇杆的兼容性问题；真实硬件范围仍以验证记录为准。
- 启用操作采集时，随本次录制完整保存键鼠和手柄输入，独立保存窗口状态；回看默认全部显示，并提供仅游戏前台筛选。窗口切换不再丢弃后台输入，真实设备断开和采集异常仍单独记录。
- 修复前台观察失效引发的大量重复缺口；旧资料的异常点在回看中合并，缩放按可见区域绘制。保留原始数据，不虚构丢失操作。
- 空闲就绪检查和刷新设备改为读取原生设备标识，不再反复创建、删除 OBS 临时源，移除已观察到的源生命周期崩溃触发路径。开始录制时仍核对实际源和音轨。

## 超宽视频与回看

- 新录制根据实际源尺寸设置 OBS 画布与编码比例；3440×1440 源在 1080p 预设下输出 1920×804，避免额外写入上下黑边。
- 初始回看窗口跟随所在显示器工作区；视频按剩余宽度和可用高度保持比例，支持手动分栏。没有有效操作记录时压缩下方空白区域。
- 对已核对的旧视频黑边提供显示配置与恢复原画面入口，只调整呈现，不更改原始视频或时间。

## 说话人和记录者

- 新 Qwen 录音转写启用说话人分离并保留编号；按说话时长和典型麦克风音量推荐记录者。
- 回看可试听、手动指定、不指定或恢复推荐。手动选择绑定当前逐字稿，重新转写不会误用旧编号。
- 推荐保留不确定性；音量不等于麦克风距离，旧场次不自动重转写。升级后恢复已有云端任务时沿用原请求，避免重复提交。

## 外部 agent 预处理

- 录像、转写与独立回看文件整理完成后，最后发布 `agent-ready.json`。提供领取、续期、证据读取、截图、校验、提交和状态查询接口，防止重复提交及过期 worker 覆盖新结果。
- 无 agent 时，记录、转写、回看和导出独立可用。有当前版本的有效结果时，主列表显示处理标记，回看增加可定位原始证据的体验事件。
- 新增可独立安装的 `skills/think-aloud-preprocess`，区分原话、观察、推测与资料缺口，整理体验事件、探索想法及可选问题。
- 采用用户手动发起的单次任务；可复用提示词见 [接口文档](agent-integration.md#手动发起一次预处理)。不随软件安装定时任务、常驻 agent 或云端上传流程。
