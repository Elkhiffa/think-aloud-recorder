# Think Aloud 0.11.0

- **问题类型改为设计缺陷**：单场整理按“游戏的哪个设计有缺陷”分成 10 类：信息缺失、表意不明、预期传达有误、反馈缺失或延迟、视觉层级、操作阻断、操作困难、功能缺失、体验与价值、表现错误，另有观察。玩家卡在哪一环（表象）照常记录，用来取证，不进列表和筛选。场次库、洞察和导出都认新类型；旧场次保留原来的类型，以灰色显示。
- **操作记录视频**：agent 提交整理结果时，软件按它标出的证据片段生成无声 MP4（1920 宽，下方带操作条），存在场次的「证据视频」文件夹，打包分享时不带。
  - 场次库的问题行：点「操作记录 N 秒」，就地播放。
  - 洞察的证据卡：点缩略图，在大图里播放。
  - 回看窗口：点区间按钮，跳到这一段播放。
- **导出带视频**：`think-aloud-export` 把视频以文件卡片放进表格，命名为“操作记录录屏NN”，有两个截图列时放第二列，否则放备注列。这一步要用 ego 浏览器；放不上的会列出来，手动拖进去即可。导出时遇到写不清或对不上的行，会回到素材核对。
- **单场整理规则更新**（`think-aloud-judgments`，按多轮人工标注修订）：
  - 看过程，不看结局：受阻和理解困难都记成问题，事后弄懂或说“没问题”不抵消。记录者是设计师，一般玩家未必过得去。
  - 强度改为对玩家的影响：1 自己很快恢复；2 走错、绕路或明显花了时间；3 放弃、卡死或被迫换设备。
  - 同一个界面或控件、同一种缺陷，才合成一条。
  - 玩家说某个操作没成功，只当线索，先查是否真的失败；其实成功了，就记成功反馈不足。
  - 新增复核流程：可以先用一个模型整理，再用另一个模型按 `references/复核.md` 补漏。
- **键鼠可能未采集的提示**：游戏以管理员身份运行、而记录器没有时，键鼠操作采不到，早期版本也不标缺口。这类场次在回看页和 agent 证据里会提示“键鼠可能未采集”，免得把空白当成玩家没操作。
- **重新整理时不再带出旧结果**：agent 重新整理一场时，读到的状态和证据不再包含上一次整理的类型、原话和标题。
