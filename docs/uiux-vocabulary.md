# 内置 UI/UX 术语库

安装目录中的 `vocabularies/uiux-terms.txt` 是可直接查看、编辑和导入的 UTF-8 词表。
146 个通用短词覆盖 UI/UX、控件、输入、导航、反馈状态与游戏交互；不包含特定公司、
项目或用户词库。这份原创汇总沿用本项目的 MIT 许可证。

首次设置与新建预设会默认选用该文件；「语言与词库」收起时显示「UI/UX 已选」。
展开后，每份已选词库都有「查看」和移除入口。查看展示的是当前预设选用的词条快照，
不会保存设置、开始录制或联网。移除后保存预设即可停用，不会删除磁盘文件。

已有预设不自动加入新词库。升级后可进入预设设置 → 录制与转写 → 语言与词库 →
选择词库文件，选择 `uiux-terms.txt`，再保存预设。文件选择器初始打开安装目录的
`vocabularies` 文件夹，也可在其中放置自用 TXT / SCEL 词库。

每份预设保存独立的词条快照。修改磁盘 TXT 不会改变已保存预设或历史场次；需移除旧词库，
重新选择文件，再保存预设。新建预设从软件启动时读取的内置文件创建默认快照。

术语只辅助识别，不是替换规则，也不保证识别正确。Qwen 模式下，已启用词条随转写参数
传给服务方。词表不含长解释或完整评价句，避免把预先写好的评价引入转写提示。

构建按固定路径收录这份词表，缺少文件则构建失败。其他个人词库和子目录都排除在
Git 与软件打包范围之外；不扫描它们作为默认词库。
