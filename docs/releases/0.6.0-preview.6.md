# Think Aloud 0.6.0-preview.6

Windows 64 位预览版，用于录制游戏体验、口述与键鼠／手柄操作，并在同一个回看窗口中分析。

## 本版更新

- 空闲时仅在记录器主窗口位于前台时自动检查录制设备和游戏源，返回主窗口后重新检查。录制中的健康检查继续运行。
- 游戏更新或重启造成窗口标识改变时，尝试匹配同一进程的唯一窗口；存在多个候选时仍要求选择，不会录错窗口。
- 开始录制时显示实际准备阶段。回看将正常启动区间标记为“录制准备”；有可靠时间校准时，从准备完成处暂停打开，仍可拖回开头。保留既有键位／视频时间校准，不叠加固定延迟，不隐藏真实采集中断。
- 包含此前的紧凑目录、可拖动原话浮层、长按标签、等宽键位列、时间轴滚轮浏览和设备图最近操作渐淡显示。
- 自带并默认启用 444 词 UI/UX 术语库，包含 tab、tooltip、tips、hover 等常用名称。

## 下载和使用

下载 `ExperienceRecorder-0.6.0-preview.6-windows-x64.zip`，完整解压到固定文件夹，运行 `Think Aloud.exe`。不要把 GitHub 自动生成的 Source code ZIP 当作软件包。

同名 `-dependency-sources.zip` 是第三方依赖的对应源码材料，无需安装或解压到软件目录；转发软件时请一并保留。`-SHA256SUMS.txt` 用于核对下载完整性。

软件根目录包含 `Think Aloud.exe`、`app/` 和 `vocabularies/`。需要系统的 Microsoft Edge WebView2 Runtime。本地转写模型为可选下载项；云端转写需填写自己的百炼 API Key。个人配置、密钥、录音和资料库均未打包。

已有紧凑目录版本可在软件内切换到预览版更新通道，再检查更新。先结束录制及后台整理，并关闭回看窗口后安装；更新会保留配置与个人资料，并留下旧版备份。更早的平铺目录版本请参照仓库 `docs/updates.md` 的迁移说明，不要直接混合覆盖两个布局。

首次使用 OBS 远程控制时，Windows 可能询问防火墙访问权限。正常使用和更新应沿用固定安装路径，避免每次解压到带版本号的新文件夹而重新询问。

## 验证与限制

本轮修复通过相关后端、浏览器、原生窗口焦点和安装自检。真实 OBS 测试使用合成窗口，并验证唯一窗口匹配及退出清理。

锁屏通知使用模拟注入验证，未进行真实 Windows 锁屏崩溃复现；不能据此保证所有 OBS 锁屏崩溃已解决。Xbox／DualSense 的实际兼容性仍需更多硬件验证。操作记录仅在所选目标窗口位于前台时采集。
