# Think Aloud 0.6.0-preview.5

用于记录游戏和交互体验：录制画面与口述，回看视频、原话及键鼠/手柄操作。

## 这一版

- 录制预设分别保存游戏窗口、麦克风、资料库、转写方式和词库；主界面保留清晰的开始录制入口。
- 前一场录制整理时可以继续下一场。视频可用后即可回看，逐字稿完成后原地更新并保持播放进度。
- 回看支持片段命名、固定视频区域，以及连续操作时间轴；点击或拖动时间轴同步调整视频进度。
- 内置 UI/UX 术语参考文件，可查看，也可以加入个人词库。
- 顶部版本入口支持手动检查 GitHub 更新、下载校验、退出安装及失败恢复；保留预设、密钥、资料库路径和个人文件。
- 更换为固定来源、附带构建材料的 FFmpeg 8.1.2；保留独立麦克风转写和原始录像恢复方式。

## 使用方式

下载 Windows x64 软件 ZIP，完整解压后运行 `ExperienceRecorder.exe`。不要下载 GitHub 自动生成的 Source code ZIP 代替软件。需要系统提供 Microsoft Edge WebView2 Runtime。

软件包不含本地转写模型。可以在设置中单独下载/选择模型，或者配置自己的百炼 API Key 使用云端转写。

从已有的支持更新功能版本升级时，先切换到预览版通道；安装需要当前工作完成并关闭回看窗口。更早版本请先保留配置和资料库，再按发布说明进行迁移。

## 已知限制

这是预览版本。手柄界面和采集路径支持 Xbox / DualSense，实际设备兼容性仍需更多硬件验证；操作记录仅在所选目标窗口位于前台时启用。

更新检查需要访问 GitHub，网络不可用时不会修改当前软件。不强制结束录制或其他占用安装目录的进程。
