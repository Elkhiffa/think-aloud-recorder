# Think Aloud 0.11.2

- **单场整理规则更新**（`think-aloud-judgments`，按全库重整前的对照批注修订）：
  - bug 先分两种：表现上的异常（重叠、截断、按键失灵等），记录者说出来就算明说；可能是有意设计的行为，要记录者断言它出错了才算明说（“这不对吧？”也算），只是问为什么或不想要这个结果的不标。同一系统别处不是这样的，记疑似。
  - 强度改为对这一趟目标的阻碍：1 没耽误手上的事；2 走错、绕路、反复试，或要靠猜做决定；3 没做成。
  - 指不出设计缺口的记观察：游戏在它安排的地方已经讲清楚，记录者只是边玩边确认，就不算问题。
  - 记录者说出忘了这一趟要做什么，算问题，按把他带离目标的设计归类。
  - 可能是有意设计的行为：游戏自己传达过相反的预期，记预期传达有误；没有，记体验与价值。
  - 游戏的已知规范：资料库 `game-assets/<游戏>/已知规范.md` 写着记录者确认过的设计约定和排查经验，整理前先读。
  - 案例里的实例编号换成全库重整后的结果。
- **跨场次分析**（`think-aloud-insight`）：强度 1 的实例照样挂到议题；定级时对照各档条数，报告写明一个问题的证据 1、2、3 档各几条。
- **转写修正**：`transcript-fix-list --session` 不再输出依据文字。依据里常带着上一次整理的实例编号和结论，重新整理一场时要独立判断；在对话里确认修正时不带 `--session`，照常显示依据。
