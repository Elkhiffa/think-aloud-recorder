# Think Aloud 0.11.1

- **软件更新时，分析 skill 和识别组件一起更新**：在软件里更新后，新版第一次启动时，会把 Claude Code、Codex、CodeMaker 里已经装过的分析 skill 同步到新版，旧版先备份；以前下载过识别组件、而新版换了组件时，也会在后台重新下载。主窗口会提示同步到了哪些 agent。没装过的 agent、没装过的 skill 不会被新装；之后再启动也不会重复覆盖，你在更新后改过的 skill 会保留到下一次软件更新。约 3 GB 的本地转写模型不自动下载，仍在设置里单独提示。
- **手动安装分析 skill 时写明版本**：内容已和当前软件一致时，结果显示“已是最新（与 0.11.1 一致）”。
