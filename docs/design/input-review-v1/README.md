日期：2026-09-22。阶段：视觉评审。使用内置 imagegen 生成，未修改生产界面和采集功能。画面中的游戏场景为合成示意。

- [当前按键](01-current-keys.png)：暖纸底、砖红激活态、鼠标键盘输入及固定轨道。
- [手柄与原话浮层](02-controller-speech.png)：同窗口中的 Xbox 设备图、左右摇杆图素及精简后的原话浮层。

时间轴在视频右侧，依次为时间刻度、原话、方向、指向、其它按键。方向包括 WASD 与左摇杆，指向包括鼠标移动与右摇杆，其它按键紧凑靠左排列；同一区间不重叠的按键复用最左空位。

最新交互约定：

- 光标在时间刻度右侧内容区：滚轮调整播放进度。
- 光标在纵向时间刻度区：滚轮快速调整时间轴缩放。
- 原话 hover 展开，点击固定；点击外部、关闭按钮或 Escape 隐藏。
- 浮层只有时间、正文、关闭按钮；去掉“已固定”和“定位到此处”。

设计默认：滚轮缩放以指针所在时间为中心；调整进度保留播放/暂停状态。当前仅记录默认，未完成运行验收。

生成图用于确认视觉层级，不替代交互合同和精确几何规格。最终实现仍须保持视频源比例、按实际时间计算条高、准确的手柄按钮布局及最左空位复用；图中的刻度和条位置存在示意误差。

完整生成与修订提示词见 prompts.md。当前浏览器原型尚未同步最新滚轮和浮层修改。
