# Think Aloud Recorder

Windows 游戏体验记录器：录下游戏画面与口述，在独立窗口同步回看录像与口述逐字稿。

## 使用

1. 完整解压 Windows x64 便携包，运行 `Think Aloud.exe`。
2. 新建录制预设，建议用游戏或项目命名；在向导选择录制窗口或显示器、麦克风、画质、转写方式与保存位置。每套预设可使用不同资料库。
3. 保存一次，以后选择预设并点击 **开始录制**。选定窗口未打开、麦克风不可用、模型或密钥缺失时，按钮会禁用并显示具体原因。
4. 结束录制并保存后即可开始下一段；上传与转写在后台逐段排队，进度显示在对应场次。视频就绪后即可打开独立回看窗口，不必等待转写；可以同时打开多个场次。场次详情提供导出与重试。

首次设置默认将资料库建在软件父级目录下的 `think-aloud-database`，多个版本放在同一父目录时可沿用此位置。若目录已存在，向导会询问是否使用已有资料库，也可选择其他位置；确认并完成设置后才会创建或使用它。已保存的预设继续使用原路径，不自动搬动已有资料。

需要 Windows 10/11 x64 和 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。软件不安装全局 Python、不改变系统代理。

## 软件更新

点击主窗口顶部的版本号，打开「版本与更新」。手动检查 GitHub Release、下载并校验后，在工作结束时点击「退出并更新」。正式版为默认通道，预览版需要主动选择；没有 Release、已经是最新版和网络失败会分别显示。

安装沿用当前目录，保留预设、资料库路径、本机密钥、模型、回看偏好和用户词库。录制、保存、整理、导出等工作尚未结束时不能安装；确认更新会关闭全部回看窗口。更新事务保留旧版备份，失败时恢复或给出明确的恢复入口。详见[更新说明与发布准备](docs/updates.md)。

## 转写方式

- **本地 Whisper large-v3**：在本机处理；模型约 3.09 GB，独立于软件包。向导可下载固定版本，或校验并直接引用已有模型文件夹，不复制权重。默认使用 CPU。
- **Qwen 云端转写**：使用自己的百炼 API Key。选择云端转写后，只将麦克风独立音轨上传到服务提供方，可能产生服务费用。密钥使用当前 Windows 用户的 DPAPI 加密保存，不进入场次导出。

向导以「本地转写」「Qwen 转写」两个并列选项呈现。新预设默认选中本地转写；不会自动下载模型或上传音频。旧版本保存的“仅录制”预设继续保留，编辑时需要明确选择一种转写方式，保存后才生效。

模型清单固定上游版本和每个文件的 SHA256。支持暂停与断点续传；文件校验通过后才能用于转写。软件升级不要求重新下载模型。换到新软件目录时，可重新引用原模型目录和资料库。

向导中的「语言与词库」支持多选 TXT / 搜狗 SCEL 词库，展示文件名与词数，可查看词条或逐项移除，重复词条自动合并。提供[搜狗官方词库下载入口](https://pinyin.sogou.com/dict/)，也可展开「手动补充词条」。词库内容随各自预设保存，原文件移动后仍可使用；需要更新内容时重新选择文件。

软件安装目录自带 `vocabularies/uiux-terms.txt`，包含 440 个通用 UI/UX、界面控件、焦点状态与游戏交互术语。首次设置和新建预设默认选中，折叠的「语言与词库」也会显示「UI/UX 已选」；展开后点「查看」可阅读实际选用的词条。已有预设与主动移除的词库保持原样，可手动选择该 TXT 加入。词库文件选择器默认打开 `vocabularies` 文件夹，打包仅收录这份内置词表，不收录用户放入的其他词库。详见[词库说明](docs/uiux-vocabulary.md)。

## 回看与资料

从场次列表点击 **回看**，打开可拖动、缩放的独立窗口。视频区域固定，逐字稿列表单独滚动。点击原话定位并播放对应视频；当前句自动高亮。手动滚动暂停跟随，点击“恢复跟随”继续。

拖动视频和逐字稿之间的分隔线，可自由调整两边的占用比例。宽窗口左右调整，窄窗口上下调整；两种布局分别记住比例，已打开的多个回看窗口互不影响。双击分隔线恢复默认；分隔线获得焦点时可用方向键微调，Shift 加方向键加大步幅，Enter 恢复默认。缩小窗口会保留两边的基本操作空间，放大后恢复你选择的比例。

播放器使用随软件离线提供的 Plyr 3.8.4。支持点击/拖动进度条、空格播放/暂停、左右方向键前后 15 秒、音量、倍速与全屏。快捷键只影响当前窗口，在搜索框输入时不触发。

顶部片段信息旁提供分体复制按钮，不覆盖录像：直接点击 **复制资料库路径**，复制本场次所属资料库路径，方便交给 agent；点击右侧箭头，可单独复制逐字稿 JSON、视频路径，或打开复盘与逐字稿文档。复制成功后图标变为对号、文字显示 `copied!`，两秒后恢复，不改变视频区域大小。旧场次读取已有时间戳和逐字稿，无须重新转写；导出时生成新版离线网页。

每个片段可以单独命名：在主界面列表或桌面回看页点击名称旁的编辑图标。片段名最多 100 字，留空恢复游戏／项目名称；不会改动预设名称或资料文件夹。后台整理和重新转写会保留这个名字，已打开的桌面回看页会同步更新。离线导出页展示导出时的名称，不提供无法持久保存的改名入口。

## 操作记录

在预设向导中选择 **游戏窗口** 后，可以勾选「同时记录键鼠与手柄操作」。默认关闭；改为录制整个显示器后自动关闭。只有选中的目标窗口在前台时才采集，切出时留下明确的记录缺口。键鼠使用 Windows Raw Input，手柄使用随便携包提供的 SDL2；支持 Xbox／DualSense 的按钮、扳机和摇杆映射。真实设备兼容性验证范围见 [采集验证记录](docs/input-capture-validation.md)。

回看页的视频下方可切换「当前按键」「设备图」或收起。键鼠与手柄按最近有效操作自动切换，摇杆漂移不会直接抢占显示。右侧「操作时间轴」从左到右为时间刻度、原话、方向、指向、其他按键；按实际起止时间显示长按和重叠，WASD／左摇杆、鼠标移动／右摇杆使用固定轨道，其余按键紧凑排列。

连续摇杆、鼠标移动及扳机的相邻采样显示为活动带，保留内部方向变化，悬停可查看对应时刻的输入。短按键帽至少高 28 像素，显示区域重叠时向右占用空列；缩放后重新排布，宽度不足时只在时间轴内横向滚动。键帽边线表示真实持续时间，扩大显示不会延长按下状态，也不会合并重复按下；已有场次直接使用新版显示，无需重新录制。

鼠标位于时间轴内容区时，滚轮调整播放进度；位于左侧时间刻度时，滚轮调整缩放。悬停原话条查看内容，点击固定，点击其他位置或按 Escape 关闭。转写尚未完成时，「转写中」页签不可切换；完成后自动变为「原话」，保留当前播放进度、播放状态和倍速。

点击时间刻度或时间轴空白处可定位视频；在时间轴中按住左键上下拖动，可连续调整进度。视频、播放头和当前按键同步更新，播放或暂停状态及倍速保持原样。手动定位后时间轴保留当前浏览范围，点击「恢复跟随」重新跟随播放。直接单击原话条仍固定文本，拖动原话条则调整进度；直接单击按键条保留定位到该次操作的功能。

操作数据单独保存在场次中，不嵌入视频。旧场次无须转换；未开启、采集失败、失焦缺口分别显示。操作记录随场次一起导出。

关闭主窗口后，已经打开的回看窗口继续保留；最后一个窗口关闭后程序退出。普通设备检查不再阻止关闭。若仍在录制或整理，会明确询问是否结束录制并等待保存、整理完成后自动关闭，不会悄悄最小化。

主录制窗口安全关闭后，会正常退出本次由记录器启动且已空闲的 OBS，回看窗口仍可继续使用。手动打开的 OBS、正在录制或推流的 OBS，以及无法确认来源或状态的进程都不会被强制结束。升级前请先退出旧版记录器遗留的 OBS；新版不会接管没有启动记录的旧进程。

完整解压导出的场次后，也可以用浏览器打开“独立回看.html”；播放器资源已嵌入网页。浏览器不能直接调用资源管理器时，文件夹按钮会复制路径。

每个场次独立保存原始 MKV、回看 MP4、口述音频、带词级时间戳的逐字稿和 `复盘.md`。重新转写保留旧稿与手写笔记。导出包含所选场次和离线回看网页。已有复盘、历史逐字稿与旧资料库保留，不安装或导出 Obsidian 插件。

录制保存两条音轨：第 1 轨用于游戏声音与麦克风混合回放；第 2 轨仅包含选定麦克风，是唯一转写输入。扬声器传到麦克风的环境声音仍属于实际麦克风输入，音轨分离本身不会消除它。

## 开发与构建

核心为 Python + OBS WebSocket；界面为本地 HTML/CSS/JavaScript + pywebview/WebView2；耗时转写在独立进程运行。无需前端打包服务或远程网页。

```powershell
runtime/python.exe -m unittest discover -s tests
runtime/python.exe app.py
runtime/python.exe scripts/build_portable.py --outdir dist/candidate --candidate
```

准备运行环境、构建范围与依赖源码材料见 [构建说明](docs/build.md)。`--candidate` 生成供本地验证的包；公开二进制发行需满足构建器检查的第三方源码条件。源码许可证不自动涵盖第三方二进制。

GitHub 首次发行、三件套校验和当前依赖缺口见 [Release 准备状态](docs/release-readiness.md)。发布前运行 `scripts/prepare_release.py`；它仅检查本地产物并准备草稿，不上传文件或公开发布。候选包不能作为软件内更新的发布附件。

实现约定见 [AGENTS.md](AGENTS.md)，体验要求见 [recorder-experience.md](docs/recorder-experience.md)，桌面接口见 [bridge-contract.md](docs/bridge-contract.md)。运行数据、密钥、模型与个人词库不进入 Git。

### Think Aloud 记录与回看工作台

主界面采用上下结构：上方是紧凑的录制区，下方是始终可见的体验列表；保存路径自动换行，单条片段展开后显示附加操作。主界面、设置向导和回看统一使用暖纸底色、墨色文字与砖红强调，支持浅色和深色模式。录制区与列表标题同级，录制区底色略深；开始按钮上方只显示当前就绪状态或不可用原因。回看选中原话时，以浅暖底色、红色时间戳和时间戳后的竖线标出当前句。

回看打开后按当前视频的实际宽高比自动分配视频与逐字稿区域，不改变外层窗口大小。空间不足时等比例缩小视频，保留逐字稿的可读宽度，不拉伸或裁切画面。可继续拖动分隔条手动调整；双击分隔条或选中后按 Enter 可重新适配视频。逐字稿独立滚动，视频区域保持固定。

首次设置突出「开始录制 → 体验 + 说出想法 → 回看 + 分析问题」的完整流程，再用“观察、理解、行动、感受”四类口述例子介绍记录方法；这些是可自由选择的提示。编辑已有预设只显示三个设置步骤，不再包含记录方法。平时可从首页带信息图标的“记录方法”入口查看。向导的步骤导航和底部按钮固定，内容单独滚动；它只保存预设，录制仍由首页按钮开始。

进入“游戏与设备”时，名称输入框自动获得焦点。设备列表为空时按钮显示「设置 OBS」，成功获取设备后初选系统主显示器与默认麦克风，只填入当前未保存的预设。如果无法确认默认设备，会提示手动选择；已有设备时的「刷新设备」保留手动选择。

云端密钥输入框不会回填已保存的密钥；旁边显示保存状态，并提供百炼控制台入口。页面只打开固定的控制台网址，不把输入内容发送到网址中。
